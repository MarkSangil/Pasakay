# Pasakay

Monorepo root for Pasakay apps.

```
apps/
  driver/    # Flutter driver app
  customer/  # Flutter commuter app
  admin/     # Flutter web system admin
```

See [apps/driver/README.md](apps/driver/README.md) for the driver app and [apps/admin/README.md](apps/admin/README.md) for the system admin.
